# Security Policy

## Support

LapCry is supported on a best-efforts basis. Patches are applied to the latest
version rather than retroactively to older versions. Use the newest release
from the project's GitHub Releases page.

No guarantee is offered for the correctness or security of LapCry. In
particular, the security of cryptographic operations should not be relied upon
for protecting secrets.

## Reporting a Vulnerability

If you discover a vulnerability in LapCry, do not publicly disclose it. Use
GitHub's private vulnerability reporting feature for the repository.

Include the LapCry version, reproduction steps, operating system, WebView2
version, and a minimal input or recipe when possible.
