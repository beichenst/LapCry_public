# LapCry 构建与打包说明

本目录提供从源码重新构建 LapCry 的全部步骤。源码位于交付包内的
`..\02_源代码`，构建脚本会把最终的单文件可执行程序输出到交付包根目录的
`dist\LapCry.exe`。

## 1. 构建环境

| 组件 | 版本要求 | 说明 |
| --- | --- | --- |
| Windows | 10 / 11 x64 | 目标运行平台 |
| Node.js | `>=24 <27`（推荐 24 LTS） | 前端与测试工具链，见 `02_源代码\.nvmrc` |
| npm | 随 Node.js 安装 | 依赖安装与脚本执行 |
| .NET SDK | 8.0 | 编译桌面壳 `desktop/LapCry.Desktop` |
| Microsoft Edge WebView2 Runtime | Evergreen | 运行时依赖，Windows 11 通常已内置 |

> 构建时无需联网获取业务数据；`npm install` 仅从 npm 源拉取开发依赖。
> 生成的程序在运行时完全本地执行，不访问任何 LapCry 服务。

## 2. 一键构建

在 PowerShell 中执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\一键构建.ps1
```

脚本会依次完成：

1. `npm install` 安装依赖；
2. `npm run lint` 静态检查；
3. `npm run build` 生成生产前端产物到 `build/prod`；
4. `npm test` 运行 Node API 与操作测试；
5. `dotnet publish` 发布自包含单文件 EXE；
6. 拷贝 `LapCry.exe` 与 `SHA256SUMS.txt` 到 `dist\`。

常用参数：

```powershell
# 跳过测试，仅快速出包
.\一键构建.ps1 -SkipTests

# 使用 npm ci（要求 package-lock 与 package.json 一致，适合可复现构建）
.\一键构建.ps1 -InstallMode ci
```

构建完成后产物：

```
dist\
  LapCry.exe          # 自包含单文件，双击即可运行，无需安装 .NET
  SHA256SUMS.txt      # 校验值
```

## 3. 手动分步构建

若需要逐步执行或排查问题，按顺序运行以下命令（工作目录为 `02_源代码`）：

```powershell
npm install
npm run lint
npm run build            # 产物：build/prod/
npm test                 # Node API + 操作测试
npm run testui           # UI 浏览器测试（需先完成 npm run build）
dotnet publish desktop/LapCry.Desktop/LapCry.Desktop.csproj `
    -c Release -r win-x64 --self-contained true
```

发布产物位于：

```
02_源代码\desktop\LapCry.Desktop\bin\Release\net8.0-windows\win-x64\publish\LapCry.exe
```

## 4. 桌面封装原理

- 桌面壳使用 .NET 8 WinForms，内嵌 Microsoft WebView2。
- `npm run build` 生成的 `build/prod/**` 会作为嵌入资源编译进 EXE
  （见 `desktop/LapCry.Desktop/LapCry.Desktop.csproj` 的 `EmbeddedResource` 项）。
- 首次启动时，程序把嵌入资源释放到本机缓存
  `%LOCALAPPDATA%\LapCry\runtime\`，再由只监听 `127.0.0.1` 随机端口的
  本地静态服务提供页面。
- 因此发布时只需要一个 `LapCry.exe`，不需要附带 `build/prod` 目录。

> 修改前端后必须重新执行 `npm run build`，否则 EXE 内嵌的仍是旧资源。

## 5. 打包为分发包（可选）

将 `dist\LapCry.exe`、`README.md`、`LICENSE`、`THIRD_PARTY_NOTICES.md`
放到同一目录后压缩：

```powershell
Compress-Archive -Path .\dist\LapCry.exe,`
    ..\04_文档与许可\README.md,`
    ..\04_文档与许可\LICENSE,`
    ..\04_文档与许可\THIRD_PARTY_NOTICES.md `
  -DestinationPath .\dist\LapCry_v0.0.8_win-x64.zip -Force
```

## 6. 校验

```powershell
# 校验单文件 EXE 是否与发布记录一致
Get-FileHash .\dist\LapCry.exe -Algorithm SHA256

# 或者使用随包校验文件
Get-Content .\dist\SHA256SUMS.txt
```

## 7. 常见问题

- **提示找不到 dotnet**：安装 .NET 8 SDK，而非仅运行时。
- **提示 WebView2 runtime is not installed**：安装 Evergreen WebView2 Runtime。
- **构建内存不足**：webpack 生产构建峰值较高，可在构建前设置
  `$env:NODE_OPTIONS="--max_old_space_size=4096"`。
- **EXE 未包含最新前端**：确认先执行了 `npm run build`，再执行 `dotnet publish`。
